## 1. 전제 조건

- 공정 범위: **취수 → 전처리 → RO 본공정 → 후처리** (농축수·자원화는 범위 포함, 실시간 연계 제외)
- 화면 성격: 3D 중심형 메인화면 상시 표시 KPI
- 데이터 출처: PSG 임시 DB (API 포맷 협의 필요)
- 전처리 세부 설비 구성(DAF 포함 여부, MMF/DMF 여부 등)은 **성균관대 준공 도서 확인 후 조정 필요**

## 5. 화면별 표시 구분 (Tier 분류)

### Tier 1 — 메인화면 상시 표시 (5종)

| KPI | 단위 | 표현 형식 | 선정 이유 |
|---|---|---|---|
| **에너지 소비량 (SEC)** | kWh/m³ |  | 에너지 효율의 최종 결과값. 이 프로젝트의 핵심 성과 지표 |
| **생산 유량** | m³/d |  | 파일럿 목표(10 m³/d) 달성 여부 즉각 확인 |
| **생산 수질 (TDS)** | mg/L |  | 수질 기준(TDS ≤ 500 mg/L) 충족 여부. 플랜트 존재 목적 자체 |
| **가동률** | % |  | 설비 전반 안정성 요약값 |
| **활성 경보 건수** | 건 |  | 0이면 안심, 1 이상이면 즉각 주의. **일반 알람 / 셧다운 알람을 구분 표시(색상 차별화)** *(RIST 검토의견 반영)* |

### Tier 2 — 서브 패널 또는 경보 조건 연동 (5종)

| KPI | 단위 | 표현 형식 | 역할 |
|---|---|---|---|
| **RO 차압 (ΔP)** | bar |  | 막 오염 조기 감지. 임계값 초과 시 메인화면 알림 연동 |
| **염제거율 (SR)** | % |  | 막 성능 저하 감지. 기준 ≥ 99.5% |
| **고압펌프 전류** | A |  | 설비 이상 부하 감지. 레오테크 고장예지 AI 입력값과 연계 |
| **SDI (전처리 출구)** | — |  | RO 막 오염 위험도. 기준 ≤ 3 |
| **원수 TDS** | mg/L |  | 에너지 소비량 변동의 외부 원인 판별용 컨텍스트 지표 |

> Tier 2 지표는 경보 임계값 초과 시 메인화면에 팝업 알림 형태로 노출하고,
> 상세 수치는 운영 분석 화면(PSG 담당)에서 표시하는 구조를 권장한다.

### Tier 3 — 운영 분석 화면으로 위임

NWP(정규화 투과 유량), ERD 효율, 회수율(Recovery), 약품 주입량, 여과 저항, 차압 상승률 등은
PSG 담당 운영 분석 화면에서 상세 표시한다.
