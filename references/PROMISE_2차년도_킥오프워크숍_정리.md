## 3. 3세부 통합 발표 — 태성 관련 핵심 사항

### 3.1 프로젝트 목표 지표

| 지표 | 목표값 | 규모 |
|------|--------|------|
| SEC (에너지 소비량) | 3.0 kWh/m³ | 1,000톤 |
| 생산 단가 | 0.7 USD/m³ | 1,000톤 |
| CO₂ 배출량 | 0.7 kgCO₂/m³ | 1,000톤 |

### 3.2 파일럿 플랜트 일정

| 구분 | 일정 |
|------|------|
| 해수담수화 파일럿 부지 | 사용 협의 난항으로 설치 지연 |
| 본 공정 | 3월 중 설치 완료, **4월부터 운영** 계획 |
| 농축수 자원화 공정 | 3월까지 발주 완료, 4월부터 제작·설치, **12월 운영** 계획 |

> ⚠️ **태성 영향**: 본 공정 4월 운영 시작 → BIM 라이브러리 및 모델 구축 시 공정 현황 반영 가능. 농축수 자원화 공정은 12월 운영이므로 해당 구간의 실시간 데이터 연계는 2차년도 내 어려울 수 있음.

### 3.3 SK에코플랜트

- 기존 OARO 공정을 SKEP MBC로 변경, TDS inlet/outlet 및 Recovery 관련
- P&ID 설계 후 성균관대 파일럿 연계 설치 예정

> ※ **참고**: 공정 구성 변동은 3세부 내부 사안이므로 태성이 직접 관여할 필요는 없으나, 향후 BIM 대상 공정이 확정되면 그에 맞춰 라이브러리를 구축하면 됨.

### 3.4 포스코이앤씨

- 실증플랜트 후보지: **포항 포스코퓨처엠** 최종 선정
- 실증플랜트 설계는 **앱스필(상세설계 주관)** 및 **포스코이앤씨**가 진행, **BIM은 태성 주관**
- **"BIM은 태성에서 하기로 작년에 합의했음"** — 포스코이앤씨 발표 중 확인 발언

> ✅ **태성 영향**: 실증플랜트 BIM 구축도 태성 범위임이 재확인됨. 3차년도 이후 실증플랜트 대응 준비 필요.

### 3.5 앱스필

- 퀵링크 모듈러 시공기술 개발 관련 발표

### 3.6 RIST(포항산업과학연구원)

- pH, TDS, 수온 등 모니터링 필요 언급

## 5. 1세부 통합 발표 — 태성 관련 핵심 사항

### 5.1 전남대학교 — 고장예지 모델

| 항목 | 내용 |
|------|------|
| 기반 | **유니모달** (멀티모달 아님) |
| 대상 설비 | 펌프, 배관, 밸브 포함 예정 |
| 표현 목표 (4가지) | ① 고장 발생 여부 ② 고장 유형 ③ 심각도 ④ 대처 방법 |
| 연계 방식 | 백엔드에서 계속 돌아가며 결과만 이벤트 형식으로 표출 |

> ✅ **태성 연계**: DT 시스템에서 이벤트 수신 방식으로 고장예지 결과를 3D 모니터링에 표출하는 구조 설계 필요. 레오테크 원격진단 모듈과의 역할 분담도 함께 정리 필요.

### 5.2 레오테크

- 레오테크가 개발 플로우차트를 공유함 → *(내부 소감) 태성도 유사하게 데이터 연동 및 디자인 관련 플로우차트를 작성해두면 좋겠다고 느낌*
- **MR(Mixed Reality) 개발 기능 관련**: 레오테크의 MR 관련 기능 및 UI와 태성의 3D 모니터링 기능 간에 유사한 부분이 있을 수 있음 → **각자 개발 고려 중인 기능 중 상대에게 부족한 기능을 파악·공유하여 기능성을 높이자**는 방향 합의

> ✅ **태성 액션 아이템**: 레오테크와 각자의 개발 예정 기능을 공유하고, 상호 보완할 수 있는 기능을 파악하여 시너지 도출.

### 5.3 1세부 Q&A — 태성 직접 관련 내용

| 질의 | 응답 / 결정 |
|------|-------------|
| HMI/PLC 대체 가능 여부 | 병행 설치로 이해 |
| 준공도서 관련 — 앱스필에서 2D 기반 설계 도서라도 먼저 공유해주면 태성에 도움이 되겠는가? | **2D 도면 먼저 공유해주면 큰 도움**. 3D 모델은 DT 변환 표준 충족 여부 확인 필요하므로 결과물 성격에 따라 다름 |
| 통합 시스템 언어 지원 | **영어/한국어** 지원 계획 |
| DT 시스템 12월 완성 가능? | **12월 중 프로토타입** 계획 |

## 6. 1세부 분과 회의 — 운영 및 유지관리

> 간사: RIST 주지용 수석연구원  
> 참여기관: RIST, 성균관대, 피에스글로벌, 레오테크, 태성에스엔아이, 와이즈인포텍, 전남대학교, 한밭대학교  
> ※ 주로 1세부 기관이 참여한 가운데, 운영 관련 내용 공유를 위해 3세부 일부 참여

### 6.1 실증 플랜트 운영 관련 (RIST 첨언)

파일럿 및 실증 플랜트 운영 주체는 **성균관대(주)** + **RIST(부)**. RIST에서 운영 경험 기반으로 다음 사항을 첨언함.

| 주제 | 내용 | 결론 / 방향 |
|------|------|-------------|
| 24시간 운영 방안 | 실증플랜트 목표가 장시간 연속 운영. 인력 상주 vs 원격 모니터링 vs 자동화 | 초기 24시간 상주 → 안정화 후 **원격 모니터링** 위주 전환 |
| 안전 | 신규 설비에 대한 안전 검토 필요성 제기 | (후속 확인 필요) |
| DT-PLC/HMI 호환 | DT 통합 시스템이 PLC/HMI 상위 개념인지? 호환 가능성? | 파일럿: PLC/HMI와 DT **병행**. 실증: PLC/HMI를 DT로 **대체** 계획 |
| 운영 체크리스트 | 모니터링 항목, 데이터 축적 항목에 대한 운영 체크리스트 사전 준비 필요 | (후속 정리 필요) |

> ✅ **태성 영향 — PLC/HMI 관계 명확화**: 파일럿은 병행, 실증은 대체. 이 구분은 통합 시스템 설계 시 기능 범위와 직결됨. 실증 단계에서는 DT 시스템이 운전원의 주 인터페이스가 됨을 의미.

### 6.2 데이터 센싱 관련

**전남대학교**
- 고장예지를 위한 데이터 계측기들은 펌프에 **추가 장착** 운영 (기존 설계 센서 외 별도)
- 파일럿과 실증 플랜트에서 사용되는 센서 스펙이 다를 경우 발생할 수 있는 어려움에 대해 성균관대에 공유 요청

**피에스글로벌(PSG)**
- 어떤 센서가 어디에 어떻게 설치되어 어떤 데이터를 취득하는지 준공도서 상으로 확인 불가 → 성균관대에 확인 요청
- 1세부 데이터 센싱 범위의 확인 및 필요사항 반영 주체를 아래와 같이 정리

| 구분 | 내용 | 확인·공유 주체 |
|------|------|---------------|
| **기존 운영 데이터** | 각 설비별 전력 사용량 + 온도·압력·유량·전도도 (전단/후단 모두 센싱). 현재 계측되는 데이터의 범위를 확인하여 공유 예정 | 성균관대 |
| **연구용 추가 수집 데이터** | 성균관대로부터 기존 운영 데이터 목록을 공유받은 후, 파일럿 본 공정(RO) 대상으로 추가 계측이 필요한 데이터를 정의하여 공유 | 1세부 참여기관 |

> ✅ **태성 영향**: 성균관대에서 기존 계측 데이터 범위를 확인·공유하면, 이를 기반으로 DT 시스템의 데이터 수신·표시 항목을 구체화할 수 있음. PSG 임시 DB의 데이터 포맷 협의 시에도 이 목록이 기준이 됨.

### 6.3 파일럿 플랜트 운영 기간

- 2차년도 **4월부터 4~5차년도까지** 계속 운영 계획

### 6.4 통합 모니터링 시스템 운영자 요구사항 관련

| 발언 기관 | 내용 |
|-----------|------|
| **태성에스엔아이** | 실제 운영 주체의 요구사항이 반영되어야 완성도 높은 결과물 도출 가능. 연구개발계획서 기반 내부 안은 있으나 검토 필요 |
| **RIST** (→태성) | 계획과 실제 운영 간 괴리가 있으므로 운영하면서 손봐야 함. 다만 **기본 요구사항은 최대한 빨리 문서화하여 공유**하겠음. 기본 운영 매뉴얼은 포스코이앤씨에 요청하면 얻을 수 있음 → 이후 발표에서 1세부가 포스코이앤씨에 요청, **공유해주겠다고 답변** 받음 |
| **성균관대** (→태성) | **태성이 작성한 와이어프레임을 공유받고**, 이를 토대로 3D 모니터링·2D 대시보드 등에 어떤 내용이 들어가면 좋을지 **문서화하여 공유**하겠음 |

> ✅ **태성 액션 아이템**:
> - 메인화면 와이어프레임을 성균관대에 공유 → 성균관대가 이를 기반으로 요구사항 문서화 예정
> - RIST 기본 요구사항 문서 수신 대기
> - 포스코이앤씨 기본 운영 매뉴얼 수신 대기
